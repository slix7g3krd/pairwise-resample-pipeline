# pairwise-resample-pipeline

48kHz 对白插进 44.1kHz 工程，人声一会儿快一会儿慢，切设备后还多了半拍延迟：重采样按固定比例算步长，可变帧率素材的时间基没换算；抗混叠滤波器截止频率写死，降采样时高频折返；多声道各跑一个重采样器，声道间相位漂移；分块处理时块边界没重叠，接缝处出现咔哒；重采样延迟没补偿，音画同步差几毫秒；设备切换采样率后滤波器系数没重建，声音变闷；重采样后的样本没做限幅，峰值溢出削波；抖动噪声按固定幅度加，安静段底噪明显；seek 后重采样器状态没重置，前一段尾音混进来；多轨工程只重采样主轨，伴奏轨时长不一致；硬件重采样和软件重采样各跑一次，二次失真；缓存按文件路径，换采样率后仍用旧 PCM；重采样线程和混音线程共享缓冲，读写指针互相追赶。audio/resample_pipeline.py 是核心，tests/test_resample_pipeline.py 15个红。要修的是：可变时间基；抗混叠；多声道相位；块重叠；延迟补偿；设备系数；峰值限幅；抖动控制；seek 重置；多轨一致；软硬去重；缓存隔离；线程同步。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
